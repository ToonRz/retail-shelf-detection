Shelf Agent ↔ Web MOCK

โครงการเชื่อมต่อแบบ zcrX / zcrAgentX: repo agent แยก ออก release เอง แล้ว web pin เวอร์ชันด้วย agent.version และ bump มาใช้ · ตัดสินแล้ว: รัน model ใน browser ไม่มี server · ทุกข้อมูลในหน้านี้เป็นของปลอม ยังไม่มีอะไร implement

shelf-agent-js/1 (ร่าง)

contract ไม่ใช่ HTTP แล้ว แต่เป็น API ของ library ที่ web เรียก · web รู้จัก agent ผ่านแค่ 2 ฟังก์ชันนี้กับ manifest

// retail-shelf-web
import { load } from `/agent/${AGENT_VERSION}/shelf-agent.js`;   // AGENT_VERSION มาจาก agent.version ตอน build

const agent = await load({
  baseUrl: `/agent/${AGENT_VERSION}/`,   // หา manifest.json, model, ort/ จากที่นี่
  backend: "webgpu",                    // ถ้าไม่มี ตกไป "wasm" เอง
});
// load() ตรวจ: manifest.version === AGENT_VERSION, contract === "shelf-agent-js/1",
//              sha256(model) === manifest.model.sha256  — ไม่ตรงคือ throw

const result = await agent.detect(imageBitmap, { conf: 0.25 });
// result

  "latency_ms": 38,

พิกัด xyxy เป็น pixel ของรูปต้นฉบับ (agent แก้ letterbox กลับให้แล้ว) · ค่า conf/iou ตั้งต้นเท่ากับที่ใช้ประเมินใน repo นี้

เรื่องเลือกสถานะเหตุผล
agent รันที่ไหนใน browser (onnxruntime-web)ตัดสินแล้วฟรี 100%, ไม่มี server ให้หลับตอน demo, รูปไม่ออกจากเครื่อง
ภาษาของ agentJS/TS (+ script Python สำหรับ export onnx)ตามมาจากข้อบนbrowser รันได้แค่ JS/WASM
modelYOLOv8nตัดสินแล้วผลใน README: v8n เร็วกว่าเกือบ 2× และ mAP ต่างแค่ 0.76 pp · ไฟล์เล็กพอโหลดผ่านเว็บ
model อยู่ใน release ไหนใน release ของ agent เลยตัดสินแล้วpin ตัวเดียว, กันโค้ด preprocess/NMS กับ model คนละเวอร์ชัน
host เว็บGitHub Pagesตัดสินแล้วฟรี, deploy จาก repo ด้วย Actions · Vercel ก็ฟรีถ้าอยากได้ preview ต่อ PR
เซ็น releaseSHA256SUMS อย่างเดียวตัดสินแล้วพอสำหรับโปรเจกต์ · Sigstore แบบ zcrAgentX เพิ่มทีหลังได้

ตัวเลือกที่ไม่เอา

Edge (agent ที่ร้าน) — ต้องมีเครื่องจริง + fleet, enroll, heartbeat, หลาย platform · เกินขอบเขตงานส่ง

Sidecar บน Hugging Face Spaces / Render — ฟรีแต่ server หลับเมื่อว่าง ปลุกครั้งแรกรอนาน · Render free RAM น้อยเกิน torch

ถ้าวันหลังต้องการ edge จริง: release เดียวกันยังใช้ได้ แค่ห่อ shelf-agent.js ด้วย runtime อื่น

ความเสี่ยงที่รู้อยู่

  • มือถือ/เครื่องเก่าที่ไม่มี WebGPU จะช้า (WASM) — ควรวัดจริงก่อนพรีเซนต์
  • ต้องเขียน letterbox + NMS ใน JS ให้ได้ผลเท่ากับ Ultralytics — ทดสอบโดยเทียบกล่องกับ results/predictions_yolov8n.jsonl
  • โหลดครั้งแรก ~12 MB + wasm — แสดง progress bar
