## บทพูดย่อ

1. **ชื่อ/สมาชิก** – "โปรเจกต์ของเราคือการตรวจจับและจำแนกสินค้าร้านค้าปลีก 110 ชนิด โดยเทียบ YOLOv8 สองขนาด"
2. **ปัญหา** – "ร้านค้าต้องระบุสินค้าทีละชิ้นทั้งวัน บาร์โค้ดต้องหาและหันให้ตรง ถ้ากล้องธรรมดาบอกได้ว่าเป็นสินค้าอะไรก็ทำ self-checkout ได้
   คำถามคือโมเดลเล็กพอไหม และควรใช้ตัวเล็ก (n) หรือตัวใหญ่กว่า (s)"
3. **ข้อมูล** – "ใช้ dataset Sell Products จาก Roboflow 13,557 รูป 110 คลาส เกือบทุกรูปเป็นสินค้าชิ้นเดียวถ่ายใกล้ ๆ
   คลาสไม่สมดุลเล็กน้อย มากสุดต่อน้อยสุด 3.3 เท่า"
4. **ขั้นตอน** – "เริ่มจาก weights ของ COCO แล้ว fine-tune 25 epoch ด้วยค่าเดียวกันทั้งสองโมเดลเพื่อให้เทียบกันได้
   loss ของ train กับ valid ลดลงไปด้วยกัน ไม่มีสัญญาณ overfitting"
5. **ตัวชี้วัด** – "ตัวหลักคือ mAP ของงาน detection และเพราะรูปมีสินค้าชิ้นเดียว เราแปลงเป็นงานจำแนกระดับรูปเพื่อรายงาน accuracy กับ AUC ด้วย
   และวัดความเร็วต่อรูป"
6. **ผล** – "ทั้งสองโมเดลได้ mAP@0.5 ประมาณ 0.98 และทายถูก 566 จาก 567 รูปเหมือนกัน ตัว s กรอบแนบกว่าเล็กน้อย +0.76 จุด
   แต่ช้ากว่าเกือบ 2 เท่าบน GPU และเกือบ 3 เท่าบน CPU"
7. **กราฟ** – "confusion matrix ที่ confidence 0.25 ไม่มีช่องนอกแนวทแยงเลย คือไม่ทายสลับคลาสแม้สินค้าแบรนด์เดียวกันต่างรส"
8. **วิเคราะห์** – "รูปเดียวที่ผิดคือหาไม่เจอ ไม่ใช่ทายผิดชนิด และเมื่อเปิดดู 9 กล่องที่พลาด พบว่า 8 กล่องเป็น label ที่ผิดใน dataset เอง
   เช่น กล่องเป็นจุดเล็ก ๆ หรือกล่องซ้ำ"
9. **Prototype** – "เรานำโมเดลไปทำเว็บแอป อัปโหลดรูป วิดีโอ หรือถ่ายจากกล้อง แล้วได้กรอบกับรายการสินค้าทันที"
10. **สรุป** – "โมเดลตอบโจทย์การระบุสินค้าทีละชิ้น ผลใกล้เคียง baseline ของ Roboflow แต่ไม่ได้ดีกว่า เราเลือก YOLOv8n เพราะแม่นเท่ากันในระดับรูปแต่เร็วกว่า
    ข้อควรระวังคือ test มีภาพที่ถ่ายต่อเนื่องกับ train 90% ตัวเลขจริงจึงน่าจะต่ำกว่านี้ งานต่อไปคือแบ่งข้อมูลใหม่ตามชุดภาพ แก้ label และทดสอบกับภาพชั้นวางจริง"

## คำถามที่อาจถูกถาม

* **ทำไม accuracy สูงขนาดนี้?** ข้อมูลง่าย (ชิ้นเดียว กล่องใหญ่) และ test มีเฟรมติดกันกับ train (ข้อ 7.7 ใน README)
* **Accuracy/AUC ของ detection คิดอย่างไร?** แปลงเป็นระดับรูป: label = คลาสที่มีกล่องมากสุด, คำทำนาย = กล่องที่ conf สูงสุด ≥ 0.25 (ข้อ 6.2)
* **ต่าง 0.76 pp มีนัยสำคัญไหม?** ทดสอบแบบจับคู่ 110 คลาส Wilcoxon p = 0.0013 แต่ 5 คลาสให้ส่วนต่างเกือบ 2 ใน 3 และเทรน seed เดียว
* **ใช้กับชั้นวางจริงได้ไหม?** ยังสรุปไม่ได้ dataset มีรูปหลายชิ้นจริงใน test แค่รูปเดียว
* **ทำไมไม่เทียบ paper?** ไม่มี paper ที่ใช้ dataset นี้ จึงเทียบกับโมเดลที่ Roboflow เทรนไว้บนหน้า dataset
